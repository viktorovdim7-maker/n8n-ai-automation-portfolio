# Automation Services

## Fast workflow repair

For existing n8n workflows that are failing, producing bad data or stopping at an API step.

Typical scope:

- reproduce the error;
- inspect node configuration and payload shape;
- fix API/webhook/JSON logic;
- test the corrected path;
- provide a short explanation of the fix.

## Small fixed-price automation

Examples:

- form/webhook → validate → CRM or spreadsheet;
- email → extract structured data → route/notify;
- API → transform JSON → another API;
- lead intake → classify → prepare response;
- scheduled sync between two services.

## AI-assisted workflow

Add an LLM step where it creates measurable value, for example:

- classify inbound requests;
- extract structured fields from unstructured text;
- draft a response for human approval;
- summarize incoming records;
- enrich catalog/product data.

AI output is treated as untrusted input: important fields are validated before downstream actions run.

## Deployment / reliability

I can also help move automations to a Linux/VPS + Docker environment and add logging, retries and failure paths.

## Engagement types

Available for urgent fixes, paid trials, fixed-price tasks and ongoing automation development.
